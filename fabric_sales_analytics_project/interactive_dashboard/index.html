🥉 Bronze Layer — Raw OneLake Landing Ingestion

🥈 Silver Layer — Cleaned, Conformed & Deduplicated
PySpark notebook 02_silver_sales_transformation.py applies schema casting, null handling, fulfillment duration calculations (FulfillmentDays), and merges sales lines into silver_sales.
🥇 Gold Layer — Kimball Star Schema with V-Order
Notebook 03_gold_star_schema_modeling.py models gold_dim_date, gold_dim_customer, gold_dim_product, gold_dim_store_region, and gold_fact_sales with Parquet V-Order optimization and Z-Order clustering for sub-second Direct Lake query speeds.
⚡ Power BI Direct Lake Mode Semantic Model
